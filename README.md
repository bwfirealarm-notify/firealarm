# BW Fire Alarm — หน้าสถานะ

หน้าเว็บแสดงสถานะระบบแจ้งเตือนเสริม (ตัวส่งชั้นใต้ดิน → EMQX Cloud → ตัวรับเคาน์เตอร์ชั้น 2)

- เปิดหน้าเว็บ: ดูลิงก์ใน Settings → Pages
- ต้องใช้รหัสผ่านของผู้ใช้ `dashboard` (อ่านได้อย่างเดียว)

> ⚠️ ระบบนี้เป็นการแจ้งเตือนเสริมเท่านั้น ให้ยืนยันสถานะที่หน้าตู้ NOTIFIER ทุกครั้ง
