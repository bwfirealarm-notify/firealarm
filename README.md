# BW Fire Alarm — หน้าสถานะ + ติดตั้งโปรแกรม

- หน้าสถานะ: ดูลิงก์ใน Settings → Pages (ใช้รหัสของผู้ใช้ `dashboard`)
- ติดตั้ง/อัปเดตโปรแกรม: ปุ่มในหน้าเดียวกัน ใช้ Chrome หรือ Edge บนคอมพิวเตอร์
- ไฟล์โปรแกรมอยู่ใน `docs/firmware/` (คอมไพล์โดยไม่มีรหัสผ่าน)

> ⚠️ ระบบนี้เป็นการแจ้งเตือนเสริมเท่านั้น ให้ยืนยันสถานะที่หน้าตู้ NOTIFIER ทุกครั้ง
