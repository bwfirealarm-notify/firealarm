# BW Fire Alarm — หน้าสถานะ + อัปเดตเฟิร์มแวร์

- หน้าสถานะ: ดูลิงก์ใน Settings → Pages (ใช้รหัสของผู้ใช้ `dashboard`)
- `docs/firmware/firmware.json` + `FireAlarm.ino.bin` = เฟิร์มแวร์ที่บอร์ดดึงไปอัปเดตเอง (ไม่มีรหัสผ่านในไฟล์)

> ⚠️ ระบบนี้เป็นการแจ้งเตือนเสริมเท่านั้น ให้ยืนยันสถานะที่หน้าตู้ NOTIFIER ทุกครั้ง
